ECR commands (From Local to ECR)

Run in terminal

1. aws configure
2. aws ecr create-repository --repository-name cloud-start-dash-app --region ap-southeast-2
3. aws ecr get-login-password --region ap-southeast-2 | docker login --username AWS --password-stdin (account_id).dkr.ecr.ap-southeast-2.amazonaws.com
4. 
For Windows

docker build -t cloud-start-dash-app .

For mac

docker buildx build --platform linux/amd64,linux/arm64 -t (account_id).dkr.ecr.ap-southeast-2.amazonaws.com/cloudstartdashapp:latest --push .


5. docker tag cloud-start-dash-app:latest (account_id).dkr.ecr.ap-southeast-2.amazonaws.com/cloud-start-dash-app:latest
6. docker push (account_id).dkr.ecr.ap-southeast-2.amazonaws.com/cloud-start-dash-app:latest

Create EC2 and login
AMI: Amazon Linux 2

Instance type: t2.micro

Security group: Allow inbound traffic on ports:

22 (SSH)

80 (HTTP)

8050 (Dash default port, optional)

Key pair: Create/download ec2-key.pem

Launch instance.


Install Docker and AWS CLI on EC2
# Update packages
sudo yum update -y

# Install Docker
sudo yum install docker -y
sudo service docker start
sudo usermod -aG docker ec2-user

# Install AWS CLI v2
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
exit


Connect again to Ec2 using instance connect

aws configure

aws ecr get-login-password --region ap-southeast-2 | docker login --username AWS --password-stdin (account_id).dkr.ecr.ap-southeast-2.amazonaws.com

docker pull (account_id).dkr.ecr.ap-southeast-2.amazonaws.com/cloud-start-dash-app:latest

docker run -d -p 80:8050 (account_id).dkr.ecr.ap-southeast-2.amazonaws.com/cloud-start-dash-app:latest
